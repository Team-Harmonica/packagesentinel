Questions people ask first.

How do you avoid false alarms?

One odd signal is never enough. A flag needs several that agree, such as a young package, a hidden install hook and a call to an unknown host. A single oddity is marked Review.

Do you run the package to check it?

No. Packages are unpacked and read in a sealed sandbox, and install scripts are inspected rather than executed.

Which registries are covered?

npm and PyPI, with the same checks designed to extend to other registries.
